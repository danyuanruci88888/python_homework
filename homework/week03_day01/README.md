# Week03 Day01 - 数据库基础与表关系

## 今天学了什么

今天是第一次接触数据库，主要学习了以下内容：

- 数据库为什么重要：之前的数据都存在内存里，服务一重启就没了。数据库可以长期、稳定地保存数据。
- 库、表、字段、记录的概念：数据库就像一个档案室，表像一张 Excel 表格，字段是列，记录是每一行数据。
- 主键是什么：主键是一条数据的唯一身份证，通常用自增的 `id`，不用用户名，因为用户名可能会改。
- 外键是什么：外键是一张表里指向另一张表主键的字段，用来表示两张表之间的关系。比如 `tasks` 表里的 `user_id` 指向 `users` 表的 `id`，表示这条任务属于哪个用户。
- 为什么任务表需要 `user_id`：因为任务和用户是一对多的关系，一个用户可以有多个任务，`user_id` 就是用来记录"这条任务归属于哪个用户"的关键字段。
- 设计了三张业务表：`users`、`tasks`、`job_favorites`，并标出了主键和外键。

## 遇到了什么问题

1. 一开始不太理解外键的概念，不清楚"外键到底长在哪张表上"。
2. 对主键和外键的区别有些混淆，不确定设计表时该如何判断哪个字段是外键。

## 我是怎么解决的

1. 通过多看几个例子（用户与订单、文章与评论、班级与学生），理解了外键永远长在"多"的那一侧，也就是从表里，而不是主表里。
2. 记住了一个规律：主键是本表数据的唯一标识，外键是"借用"别的表的主键来建立关联，两者职责不同，这样就不容易混淆了。
