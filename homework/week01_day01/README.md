Day 01 学习总结

1.今天学了哪些 Python 概念
    - 变量：用来存储数据的"盒子"，通过 = 赋值
    - 数据类型：字符串（str）、数字（int）、布尔值（bool）、列表（list）、字典（dict）
        - 字典：用键值对的方式存储结构化数据，类似表格
    - print() 函数：用来把变量的内容输出到终端
    
2.我觉得变量像什么
    我觉得变量像一个贴了标签的储物盒，标签是变量名，盒子里装的是数据。
    需要用的时候直接叫标签名，Python 就知道去哪里取数据。

3.哪个数据类型我最容易混淆
    我最容易混淆字符串和数字，比如 "22" 和 22 看起来很像，但一个是文字、一个是数字。
