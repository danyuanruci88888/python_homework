# 学生学习任务管理脚本

## 项目功能介绍

这是一个运行在终端的任务管理小程序，用户可以通过菜单选择操作。

主要功能包括：
- 查看当前所有任务及其状态
- 新增任务
- 将任务标记为已完成
- 自动保存任务到 tasks.json 文件，重启程序后数据不丢失
- 输入错误时有友好提示，不会导致程序崩溃

## 如何运行

1. 确保已安装 Python 
2. 进入项目文件夹：

   cd week01_day05_project

3. 运行主程序：

   python main.py

4. 根据终端菜单提示，输入数字选择对应操作

## 今天学了什么

今天是第一次独立完成一个多文件的 Python 项目。

核心知识点：
- json.load() 和 json.dump() 的区别和用法，以及 ensure_ascii 和 indent 参数的作用
- enumerate() 的用法，可以在遍历列表时同时获取序号
- try / except 异常处理，用来捕获 FileNotFoundError 和 ValueError
- 函数拆分的思路：把不同功能分别写成独立函数，而不是全堆在一个循环里
- 两个文件之间用 from ... import ... 互相调用的方式
- def 定义函数和调用函数的区别（光定义不会执行，最后要手动调用 main()）

## 我遇到了什么问题

1. 把 `from` 拼成了 `form`，导致 SyntaxError，找了一会儿才发现是拼写错误
2. `if` 条件里用了 `=` 而不是 `==`，混淆了赋值和比较
3. `open()` 的 encoding 参数忘记写参数名，直接写成了第三个字符串，导致报错
4. `show_menu()` 函数里缩进不整齐，部分 print 多缩进了一层
5. `enumerate` 拼成了 `enumerrate`，多打了一个 r
6. `task['title']` 拼成了 `task['titile']`，字母顺序打错了
7. 函数名 `save_task` 和 `save_tasks` 不统一，定义和调用对不上
8. `complete_task` 拼成了 `compete_tasks`，少了字母且多了 s

## 我是怎么解决的

遇到报错时先看终端提示的行号，找到对应代码位置。
大部分错误是拼写问题，通过仔细对比原版代码逐一排查发现的。
复习不熟悉的语法（比如 json.load、enumerate、try/except），
先弄清楚每一行的含义再动手写，避免盲目复制。
