# 项目答辩稿

## 1. 项目是做什么的？

AI 就业陪跑任务管理系统后端，面向应届生 AI 应用开发求职准备场景，帮助学生管理学习任务、收藏岗位、记录投递进度、管理技能标签，并统计学习完成情况。

## 2. 为什么做这个项目？

应届生在准备求职时，学习任务、岗位信息、投递记录分散在不同地方，难以系统管理。这个项目把学习过程和求职过程整合起来，帮助学生有条理地准备面试和投递。

## 3. 用了哪些技术？

后端使用 Python + FastAPI，数据库用 MySQL，缓存用 Redis，用户认证使用 JWT，数据校验用 Pydantic，数据库操作用 SQLAlchemy，部署环境通过 Docker Compose 启动。

## 4. 核心功能有哪些？

- 用户注册登录
- 学习任务增删改查
- 岗位收藏与查询
- 投递记录跟踪与状态修改
- 技能标签管理
- 学习进度统计（任务完成率、投递数量、技能数量）

## 5. 数据库怎么设计？

主要包含 `users`、`tasks`、`jobs`、`favorites`、`applications`、`tags` 六张表，通过外键关联实现数据隔离。每个用户只能看到自己的任务、收藏、投递和标签。

## 6. 登录鉴权怎么做？

用户登录后，后端生成 JWT Token 返回给前端。后续请求需要在 Header 中携带 Bearer Token，后端验证 Token 后获取当前用户，确保数据只能被自己访问。

## 7. Redis 用在哪里？

学习进度统计接口使用 Redis 缓存。第一次查询从 MySQL 计算并写入 Redis，后续查询直接从 Redis 返回，减少数据库压力，提高响应速度。

## 8. Docker 怎么启动？

通过 `docker-compose.yml` 一键启动 MySQL 和 Redis 两个容器，执行 `docker compose up -d` 即可。FastAPI 服务通过 `uvicorn main:app --reload` 启动。

## 9. 项目遇到的难点？

- 项目包装初期不清楚代码应该放在哪里，通过明确目录结构后解决了这个问题。
- 数据库连接和 Docker 启动过程中遇到端口冲突和连接断开问题，通过检查容器状态和重启服务解决。
- 编写路由时出现缩进错误，通过仔细阅读报错信息修正。
- 新增技能标签模块时，理解了如何扩展数据库模型、路由和统计接口。

## 10. 后续怎么升级成 AI 项目？

第二阶段可以增加：

- AI 简历优化助手
- 岗位 JD 匹配系统
- AI 面试题生成系统
- RAG 就业知识库
- AI 学习计划生成器

这个项目是第一阶段的后端底座，为后续接入 AI 能力打下基础。
